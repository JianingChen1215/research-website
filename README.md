# Quarto Research Website Demo

## 1. Install Quarto
Download and install Quarto from the official Quarto website.

## 2. Open this folder in VS Code

## 3. Preview the website
Run:

```bash
quarto preview
```

## 4. Edit content
Most content is in `.qmd` files. You can write Markdown and LaTeX directly.

## 5. Add images
Put figures into the `images/` folder, then insert them with:

```markdown
![Caption](images/your-figure.png)
```

For a project page inside `projects/`, use:

```markdown
![Caption](../images/your-figure.png)
```
